上個月一位學員在工作坊結束後問我：「Vista，你平常到底用哪些 AI 工具？網路上推薦的太多了，我不知道從哪裡開始。」

嗯，這個問題我太能理解了。

打開任何一篇「2026 年必備 AI 工具」的文章，動輒列出二三十個工具，每個都說是 game changer。但說實話，一個人做事業，你根本沒有時間一個一個去試。

所以這篇文章不是工具大全。是我**自己每天真的在用**、幫我省下大量時間的 5 個 AI 工具組合，以及我具體怎麼搭配它們的方法。

---

## 1. Claude Code——我的一人開發團隊

如果只能留一個工具，我留 [Claude Code](https://docs.anthropic.com/en/docs/agents-and-tools/claude-code/overview)。

它是 Anthropic 推出的命令列 AI 工具。簡單來說——你用自然語言告訴它你想做什麼，它幫你寫程式、改程式、甚至幫你部署。

你現在看的這個網站 [solo.tw](https://www.solo.tw)，從首頁改版、金流串接、SEO 建設到資安修復，絕大部分都是我用 Claude Code 完成的。一個非工程背景的人，用它做出了一個完整的 [Next.js](https://nextjs.org/) 網站——這件事放在兩年前根本不可想像。

我每天用 Claude Code 做的事：

**建網站和做產品。**不只是 solo.tw，我的線上課程平臺 [learn.solo.tw](https://learn.solo.tw)、各種落地頁和工具，全部是 Claude Code 幫我蓋的。

**自動化工作流程。**把重複性的工作——像是批次處理圖片、產生報表、整理資料——寫成腳本，跑一次就搞定。

**解決技術問題。**遇到 bug 或報錯，貼給它看，它不只告訴你為什麼出錯，還直接幫你修好。

即使你不是工程師，Claude Code 也值得學。我在 [learn.solo.tw](https://learn.solo.tw) 上有一門 Vibe Coding 課程，就是專門教非工程師怎麼用 AI 打造自己的數位產品。

## 2. Claude Cowork——隨時待命的協作夥伴

[Claude](https://claude.ai) 本身我用得非常重，但更精確地說，我最常用的模式是拿它來「協作思考」——我叫它 Cowork。

跟 ChatGPT 不同，Claude 在長篇深度對話和結構化思考上特別強。我不是叫它幫我寫文章，而是把它當成一個**隨時待命的思考夥伴**。

我怎麼用：

**寫作的構思階段。**我的文章還是自己寫。但在動筆前，我會把一堆零散的想法丟給 Claude，請它幫我找出邏輯線、挑出矛盾點、建議可能的結構。打個比方，就像有一個隨叫隨到的編輯，幫你把腦子裡的亂線理成一條故事線。

**課程和工作坊設計。**教案、練習題、案例分析——這些需要大量素材的工作，Claude 可以幫我在一小時內產出框架和初稿，然後我再花時間調整成自己的風格和節奏。

**[諮詢](https://www.solo.tw/consulting)前的準備。**每次 1-on-1 諮詢前，我會把客戶的背景資料丟給 Claude，請它整理出三到五個可能的切入點和要追問的問題。這樣三十分鐘的諮詢時間不會浪費在「了解狀況」上。

**決策輔助。**當我在兩個方案之間猶豫不決，我會把兩邊的利弊丟給 Claude 做 pros/cons 分析。它不會幫你做決定，但會幫你看到你自己漏掉的角度。

## 3. NotebookLM——我的第二大腦

[NotebookLM](https://notebooklm.google.com/) 是 Google 推出的 AI 知識管理工具，也是我覺得最被低估的一個。

它的運作方式跟其他 AI 不一樣。你不是丟一個問題讓它從網路上找答案——你是**餵它你自己的資料**（PDF、文章、筆記、影片連結），然後它只根據你給的內容來回答問題。

這代表什麼？**零幻覺。**它不會瞎掰，因為它只從你的資料裡找答案。

我怎麼用：

**學習新領域。**最近在研究一個新主題，我會把相關的十幾篇文章、幾本書的重點章節、幾支 YouTube 影片的逐字稿全部丟進去。然後問它：「根據這些資料，這個領域最重要的三個概念是什麼？」——它會幫我從自己蒐集的素材中整理出架構。

**備課。**[工作坊](https://www.solo.tw/courses)的教材準備，我會把過去的講義、學員回饋、相關研究報告全部匯入一個 Notebook。需要什麼素材，直接問它就好。

**寫作研究。**寫長文之前，我會建一個專屬的 Notebook，把所有參考資料丟進去。寫到一半需要引用某個數據或觀點時，問它就好——而且它會告訴你來源是哪份文件的哪一段。

最酷的功能是 **Audio Overview**——它可以把你的資料變成一段類似 Podcast 的對話，兩個 AI 主持人用聊天的方式幫你整理重點。通勤的時候聽，效率極高。

## 4. Gemini——我的視覺設計師

設計一直不是我的強項。但一人事業什麼都要自己來，總不能每張圖都外包。

[Gemini](https://gemini.google.com/) 是我目前最常用的 AI 繪圖工具。Google 的圖片生成能力在最近幾個版本進步很大，特別是在**概念插圖和幾何風格的視覺**上，品質已經非常夠用。

我用它做什麼：

**部落格 Hero 圖片。**你現在看到的這篇文章頂部的配圖，就是用 Gemini 生成的。給它一段描述——「一個人站在道路上，珊瑚紅配色，幾何風格，16:9」——幾秒鐘就出來了。

**工作坊和課程的視覺素材。**概念圖、流程圖的初稿、簡報裡的插圖。不需要完美，能清楚傳達意思就好。

**社群貼文的配圖。**不用每次都開 Canva 從模板改。直接描述你要什麼，生成、下載、發布。

一張圖省下的時間大概是 30 分鐘到一小時。一個月下來就是好幾天。

## 5. Grok——我的創意激盪器

[Grok](https://grok.com/) 是 xAI 推出的 AI，也就是 Elon Musk 那邊做的。老實說，一開始我沒太在意。但用了幾個月之後，它在我的工具組合裡佔了一個很特別的位置——**創意思考。**

Claude 擅長結構化分析，Grok 擅長跳脫框架。

我怎麼用：

**腦力激盪。**當我想不出一個好的工作坊主題、電子報標題、或行銷切入點時，我會丟給 Grok。它的回覆風格比較直接、有時候帶點幽默，常常會蹦出一些我自己想不到的角度。

**反向思考。**我會刻意問它「這個想法哪裡不好？」「有沒有人會反對？反對的理由是什麼？」它不會像某些 AI 那樣只會附和你——它真的會挑毛病。

**探索新觀點。**它可以即時存取 X（Twitter）上的資訊，所以在追蹤最新趨勢和輿論風向上特別有用。當我想知道某個話題目前的討論熱度和主流觀點，Grok 比其他工具快。

我的用法是：**先用 Grok 發散，再用 Claude 收斂。**Grok 幫我打開思路，Claude 幫我把最好的想法整理成可執行的計畫。

## 我的 AI 工具組合邏輯

回頭看這五個工具，它們不是各做各的——是一個有分工的團隊：

- **Claude Code** → 技術執行（建網站、寫程式、自動化）
- **Claude Cowork** → 深度協作（寫作、備課、決策分析）
- **NotebookLM** → 知識管理（學習、研究、素材整理）
- **Gemini** → 視覺產出（配圖、插圖、設計素材）
- **Grok** → 創意激盪（腦力激盪、反向思考、趨勢探索）

一人事業的關鍵不是「學會所有技能」，而是「讓對的工具補足你不擅長的環節」。這五個工具加在一起，基本上讓我一個人做到了過去需要四到五個人才能完成的工作量。
