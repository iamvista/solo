上個月一位學員在工作坊結束後問我：「Vista，你平常到底用哪些 AI 工具？網路上推薦的太多了，我不知道從哪裡開始。」

嗯，這個問題我太能理解了。

打開任何一篇「2026 年必備 AI 工具」的文章，動輒列出二三十個工具，每個都說是 game changer。但說實話，一個人做事業，你根本沒有時間一個一個去試。

所以這篇文章不是工具大全。是我**自己每天真的在用**、幫我省下大量時間的 5 個工具，以及我具體怎麼用它們的方法。

---

## 1. Claude——我的思考夥伴

不是 ChatGPT 不好，而是我在深度思考和長文撰寫上，更習慣 [Claude](https://claude.ai) 的風格。

我用 Claude 做什麼：

**寫作輔助。**不是叫它幫我寫文章——我的文章還是自己寫。但在構思階段，我會把一堆零散的想法丟給 Claude，請它幫我找出邏輯線。打個比方，就像有一個隨時待命的編輯，幫你把腦子裡的亂線理成一條清楚的故事線。

**課程設計。**工作坊的教案、練習題、案例分析——這些需要大量素材的工作，Claude 可以幫我在一小時內產出初稿，然後我再花時間調整成自己的風格。

**客戶諮詢前的準備。**每次 [1-on-1 諮詢](https://www.solo.tw/consulting) 前，我會把客戶提供的背景資料丟給 Claude，請它幫我整理出三到五個可能的切入點。這樣諮詢時間就不會浪費在「了解狀況」上。

---

## 2. Claude Code——一個人的開發團隊

[Claude Code](https://docs.anthropic.com/en/docs/agents-and-tools/claude-code/overview) 是 Anthropic 推出的命令列工具，簡單來說就是 AI 幫你寫程式。

你現在看的這個網站 [solo.tw](https://www.solo.tw)，從首頁改版到金流串接，很大一部分就是我用 Claude Code 完成的。一個不會寫前端的人，用它做出了一個完整的 [Next.js](https://nextjs.org/) 網站——這件事放在兩年前根本不可想像。

即使你不是工程師，Claude Code 也值得學。因為它讓你可以：

- 自己架設個人網站，不用外包
- 自動化重複性的工作流程
- 快速做出 MVP 來驗證想法

我在 [learn.solo.tw](https://learn.solo.tw) 上有一門 Vibe Coding 課程，就是專門教非工程師怎麼用 AI 做出自己的數位產品。

## 3. Cursor——寫程式的加速器

如果 Claude Code 是命令列的 AI 助手，[Cursor](https://cursor.sh) 就是編輯器裡的 AI 助手。它是基於 VS Code 改造的程式碼編輯器，內建 AI 輔助功能。

我用它做什麼：

**修改現有程式碼。**當我需要改某個元件的樣式或邏輯，直接用自然語言描述要改什麼，Cursor 會幫我定位到正確的位置並產出修改建議。

**理解別人的程式碼。**遇到看不懂的程式碼，選起來按一下就能得到解釋。對非工程師背景的人來說，這個功能救了無數次命。

Claude Code 和 Cursor 不是二選一——我是兩個都用。Claude Code 適合「從零到一」的大工程，Cursor 適合「在現有基礎上微調」的日常工作。

---

## 4. Perplexity——取代 Google 的研究工具

[Perplexity](https://perplexity.ai) 是 AI 搜尋引擎，它最大的優勢是：**直接給你答案，附帶來源。**

以前寫文章做研究，我得開十幾個分頁，一篇一篇讀，然後自己整理重點。現在我直接問 Perplexity：「臺灣自由工作者的平均收入是多少？有沒有最新的統計資料？」，它會幫我從多個來源整理出答案，而且每段都標注出處。

我每週寫 [電子報](https://iamvista.substack.com/) 的時候，大概有三分之一的研究時間被 Perplexity 省下來了。

特別適合一人事業者的場景：

- 寫部落格文章需要數據佐證
- 準備工作坊教材需要最新案例
- 研究競品或市場趨勢

## 5. Canva + AI——設計的最後一哩路

設計不是我的強項。但一人事業什麼都要自己來，總不能每張圖都外包。

[Canva](https://canva.com) 本身已經很好用了，但加上 AI 功能之後更強大：

**Magic Design。**丟一段文字描述，它幫你產出好幾個版本的設計稿，你挑一個改一改就好。工作坊的宣傳圖、電子報的配圖、社群貼文的視覺——我大概 80% 的設計工作都在 Canva 上完成。

**背景移除和圖片擴展。**一鍵搞定，不需要開 Photoshop。

**品牌套件。**把你的品牌色、字體、Logo 存成套件，每次新增設計自動套用。一致性有了，效率也有了。

## 這些工具的共同點

回頭看這五個工具，它們有一個共同特徵：**不是取代你，而是放大你。**

Claude 放大你的思考，Claude Code 放大你的技術能力，Cursor 放大你的開發效率，Perplexity 放大你的研究速度，Canva 放大你的設計產出。

一人事業的關鍵不是「學會所有技能」，而是「用工具補足你不擅長的環節」。這五個工具加在一起，基本上讓我一個人做到了過去需要三到四個人才能完成的工作量。
