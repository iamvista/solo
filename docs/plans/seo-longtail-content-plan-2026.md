## 內容策略總覽

**寫作原則（全 12 篇通用）**：

1. **長度 3,000–5,000 字**，深度 > 廣度
2. **第一手觀點 + 具體截圖／程式碼／對話紀錄**，不是教科書式整理
3. **每篇 1 個明確 H1 + 4-6 個 H2**，符合 AI 引擎抓取結構
4. **內含 FAQ 區塊**（3-5 題），讓 Google FAQ rich result 觸發
5. **每篇結尾 CTA 導向最相關的 solo.tw 課程頁**（內部連結權重）
6. **附 cover image（webp）+ 3-5 張內文截圖**
7. **發布後 24 小時內**：solo.tw 首頁 / 課程頁加反向連結指過去

**結構模板（每篇套用）**：

```
H1: [明確的長尾關鍵字句]

[Opening 200 字：講出讀者卡關的具體場景]

H2: [一句話 TL;DR 摘要 + 適合誰看]

H2: 為什麼 [X] 重要 / 為什麼大家做不好

H2: 我的實作步驟（Step 1 / 2 / 3 / 4 / 5）

H2: 三個常見錯誤與我怎麼修正

H2: 進階變化 / 延伸應用

H2: 常見問題（FAQ）—— 3-5 題

H2: 下一步：[CTA 連到課程頁]
```

## 怎麼用這份企劃

每篇文章對應一個獨立 task。執行流程：

1. Vista 從上面 12 篇選一篇 → 跟我說「動 #N」
2. 我用 [Vista 的內容創作 skill 流程](https://www.solo.tw/courses/ai-content) 跑：
   - Idea / Research / Outline → 確認大方向
   - Write 初稿 → 你 review 主軸
   - Refine 去 AI 味 + 上你的個人風格
   - 直接 commit + push 到 `~/06_VibeCoding/01_Code_Products/solo/src/content/blog/`
   - Vercel 自動部署 → 文章上線
3. 我順手做：
   - 加 BlogPosting / Article schema
   - 加 OG image（call /og 動態端點）
   - 加 4-6 個內部連結（按上面內部連結策略）
   - 內文加 FAQ 段（觸發 Google FAQ rich result）

**3-5 個月內 12 篇全部出齊**，搜尋競爭力 + AI 引擎引用力會結構性提升。
