## 一、臺灣國內競品

### 1.1 大型線上課程平臺（Marketplace 模式）

| 平臺 | 網址 | 商業模式 | 講師抽成 | 目標受眾 | 特色 |
|------|------|---------|---------|---------|------|
| **Hahow 好學校** | hahow.in | 募資 + 販售 | 平臺導流：講師拿 50%；講師自推：講師拿 90% | 臺灣/香港中文學習者 | 亞洲最大中文課程平臺，80 萬會員，月銷 7,000 堂 |
| **PressPlay Academy** | pressplay.cc | 訂閱制 + 單次購買 | 未公開（估約 30%） | 臺灣年輕族群 | 2025 年併購 YOTTA，內容大增；原以訂閱經濟為核心 |
| **YOTTA**（已併入 PressPlay） | yottau.com.tw | 募資 + 販售 | 平臺統一抽 30% | 臺灣學習者 | 已於 2025 年併入 PressPlay Academy |

## 二、國際競品

|------|------|------|--------|---------|---------|

| **Gumroad** | gumroad.com | US$0/月 | 10% + US$0.50/筆 | 獨立創作者 | 極簡銷售頁，適合低量起步 |
| **Skool** | skool.com | US$9-99/月 | Hobby 10%；Pro 2.9% | 社群型創作者 | 社群 + 課程合一，遊戲化機制 |

### 2.2 國際競品定位矩陣

```
                    功能多 ←————————————→ 功能簡
        高價  │  Kajabi          │                │
              │                  │  Stan Store     │
              │  Thinkific       │                │
        中價  │  Teachable       │  Skool          │
              │  Podia           │                │
        低價  │                  │  Gumroad        │
```

**關鍵觀察：**
- Kajabi 功能最全但價格最高，適合月營收 US$5,000+ 的創作者
- Stan Store 在社群媒體原生創作者中成長最快
- Gumroad 適合初期驗證，但 10% 抽成在規模化後成本高
- Skool 的社群 + 課程模式是 2025-2026 年最大趨勢

## 五、solo.tw 的定位優劣勢分析

### 5.1 優勢

1. **完全品牌自主** -- 自建 Next.js 網站，不依賴任何第三方平臺，品牌辨識度高
2. **技術成本最低** -- Vercel 免費/Pro 方案，年度固定成本可壓在 NT$20,000 以下
3. **學員資料 100% 掌握** -- 不像 Hahow/PressPlay 受限於平臺資料存取政策
4. **AI 主題正處於高成長期** -- 市場需求強勁，臺灣講師供給仍有限
5. **靈活度高** -- 可自由設計課程形式、定價策略、銷售流程

### 5.2 劣勢 / 挑戰

1. **無自帶流量** -- 不像 Hahow 有 80 萬會員基數，需完全靠自身行銷
2. **金流串接需自行處理** -- 需串接綠界/藍新，技術門檻較使用 SaaS 工具高
3. **課程管理功能需自建** -- 影音串流、進度追蹤、作業繳交等需開發或外掛
4. **與雷蒙三十等成熟品牌競爭** -- 對手已有萬人學員基礎與社群飛輪

### 5.3 建議策略方向

1. **差異化定位：** 聚焦「AI x 一人事業 x 實作」的交集，避免與純 AI 教學或純商業課程正面競爭
2. **產品階梯：** 免費內容（部落格/社群）→ 低價入門工作坊 → 中價線上課程 → 高價訓練營/顧問
3. **社群飛輪：** 考慮加入 Skool 或 Discord 社群，建立學員互動與口碑推薦
4. **內容行銷優先：** AI 主題 SEO 流量紅利仍在，投資內容行銷的 ROI 優於付費廣告
5. **混合模式：** 核心課程自架（solo.tw），入門課程可上 Hahow 引流回自家平臺
