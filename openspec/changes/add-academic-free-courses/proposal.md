# Change: add-academic-free-courses

## Why

`/courses/ai-academic-writing` 是三小時 NT$4,500 的實體工作坊報名頁。對主要受眾（碩博士生、研究助理）而言，這是一個需要考慮的金額，而頁面目前只有一個承諾層級：報名或離開。

Vista 已在 Mini Course Generator 上完成一套三堂的免費線上迷你課「AI 賦能學術研究」（35 課、含互動與結業證書），內容刻意設計成完整給判斷力、但不提供模板與實作帶練，模板與帶練留在工作坊。這正好補上缺少的中間承諾層級。

目的不是把流量導出去，是把原本會關閉頁面的猶豫訪客留在漏斗裡。上完三堂免費課仍願意報名的人，成交意願與課後滿意度都會更高。

## What Changes

1. `/courses/ai-academic-writing` 新增一個免費課區塊，位置在「這堂課適合你嗎？」之後、「關於講師」之前
2. 區塊內容：三張課程卡片（各自標示章數課數）、一句定位說明、一張「免費課給什麼／工作坊給什麼」對照，以及外連 CTA
3. 三個外連指向 share.minicoursegenerator.com 的公開課程網址，開新分頁
4. 課程資料集中為單一常數陣列，日後增課只改一處

## Non-Goals

- 不新增路由，不動 sitemap
- 不在 solo.tw 嵌入 MCG 內容（iframe 或 JS embed），只做外連
- 不改動 `/learn`：該頁定位是一人事業經營，學術主題掛入會稀釋其定位
- 不改動既有的報名區、價格、梯次資訊
- vista.tw 的學術專區是另一條工程線，不在本變更範圍

## Constraints

- 用詞規範：一律使用「臺」的正體寫法、中文全形標點、避免套路詞（「賦能」僅出現在工作坊與課程的正式名稱中，屬引述）
- 不得在文案中承諾免費課提供模板或一對一指導
- 免費課的定位敘述必須與課程實際內容一致：給判斷力，不給模板
- 不硬寫梯次日期與早鳥截止日，時效資訊一律以本頁既有的開課資訊區為準
