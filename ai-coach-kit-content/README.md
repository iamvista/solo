# AI 教練工坊

歡迎！這套工具包教你用 AI 建立一個每天陪你執行的實踐教練。

## 快速開始（3 步驟）

1. 安裝 Claude Code → 詳見 guide/01-install-claude-code.md
2. 執行安裝腳本 → 詳見 guide/02-install-coach.md  
3. 啟動教練 → 詳見 guide/03-first-session.md

## 套件內容

- skills/ — 4 個教練 Skill（一鍵安裝）
- coach/ — 教練模板 + Vista Coach 預建教練
- guide/ — 6 篇零基礎圖文教學
- examples/ — 3 份填好的範例檔

## 教練指令

| 指令 | 功能 | 建議時間 |
|------|------|----------|
| /solo-coach | 啟動教練 / 初始化 | 首次或需要時 |
| /solo-coach-morning | 晨間覆盤 | 每天早上 |
| /solo-coach-checkin | 下午進度回報 | 每天下午 |
| /solo-coach-weekly | 週報總結 | 每週日 |
