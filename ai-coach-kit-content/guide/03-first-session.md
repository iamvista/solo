# 第一次啟動教練

這篇教你什麼：完成第一次設定並啟動 AI 教練，讓它了解你的目標和現況。

---

## 步驟

### 1. 打開 config.md 進行設定

在 ~/solo-workspace 資料夾裡有一個 config.md 檔案，這是教練的設定檔。

用任何文字編輯器開啟它：
- macOS：用 TextEdit，或直接雙擊開啟
- Windows：用記事本（Notepad）
- 如果你有安裝 VS Code：輸入 code ~/solo-workspace/config.md

### 2. 填寫設定欄位

config.md 裡有幾個需要填寫的欄位，以下逐一說明：

name（你的名字）：
填入你常用的稱呼，例如 Vista 或 小明。

goal（核心目標）：
這是最重要的欄位，描述你在未來 90 天想達成什麼。

不好的目標範例：
- 「想讓事業更好」（太模糊）
- 「增加收入」（缺乏具體數字）

好的目標範例：
- 「90 天內讓電子報訂閱人數從 500 增長到 1,500 人，每週發一封，並測試 3 種不同主題格式」
- 「在 3 個月內完成第一個線上課程，並完成 10 次銷售」

industry（你的行業或領域）：
例如「內容創作者、部落客」或「自由接案設計師」。

coach（選擇教練）：
預設填入 vista，代表使用 Vista 教練風格。

### 3. 儲存檔案

修改完後存檔（Command + S 或 Ctrl + S）。

### 4. 啟動 Claude Code

在終端機確認你在 ~/solo-workspace，然後輸入：

```
claude
```

等 Claude Code 啟動完成，出現提示符號。

### 5. 呼叫教練

輸入以下指令並按 Enter：

```
/solo-coach
```

教練會讀取你的 config.md 並開始對話。

### 6. 回答三個校準問題

教練通常會問三個問題，幫助它更了解你：

第一個問題通常是關於你目前遇到的最大困難。
建議：具體描述，不要只說「沒什麼特別的」。

第二個問題通常是你過去嘗試過什麼方法。
建議：誠實回答，包括失敗的嘗試，這讓教練更有用。

第三個問題通常是你每天可以投入多少時間。
建議：給一個真實的數字，不要高估，例如「每天 1 到 2 小時」。

### 7. 收到教練的回應

第一次對話結束後，教練會給你：
- 針對你現況的思維框架分析
- 3 個本週可以嘗試的小實驗

這些實驗通常很具體，例如「這週試試每天早上花 15 分鐘寫一段草稿，不管品質，只求完成」。

---

## 常見問題

問：教練的建議看起來太難，我做不到怎麼辦？

答：直接在對話中告訴教練：「這個建議對我來說太有挑戰性，可以給我更小的起步動作嗎？」教練會重新調整難度，給你更容易上手的版本。

問：我回答錯誤可以重來嗎？

答：可以。直接說「我剛才說的不太準確，讓我重新描述一下」，教練會以你最新說的為準。
