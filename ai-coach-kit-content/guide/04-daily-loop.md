# 每日使用迴圈

這篇教你什麼：建立每天與教練互動的習慣，讓系統真正幫你累積進步。

---

## 步驟

### 1. 每天早上：晨間覆盤（建議時間：早上 8 到 9 點）

開啟終端機，切換到工作空間：

```
cd ~/solo-workspace
```

啟動 Claude Code：

```
claude
```

呼叫晨間教練：

```
/solo-coach-morning
```

教練會做兩件事：
1. 回顧你昨天的狀況（根據你上次 check-in 的內容）
2. 為今天設計 3 個具體調整動作

晨間對話通常只需要 5 到 10 分鐘，不必花太多時間。

### 2. 每天下午：check-in（建議時間：下午 5 到 6 點）

一天結束前，回報今天的實際狀況：

```
/solo-coach-checkin
```

這是整個系統最關鍵的環節。教練的學習和調整，全部依賴你在這裡輸入的內容。

不好的 check-in（教練無法學習任何東西）：
- 「今天還好」
- 「有做一些事」
- 「比較忙，沒什麼特別的」

好的 check-in（教練可以進行深度分析）：
- 「今天寫了 1500 字的電子報，用了系統思維透鏡來架構內容，下午發到 Facebook 後 2 小時收到 15 個留言，比平常多 3 倍，但訂閱轉換率仍然是 0」
- 「今天拜訪了一個潛在客戶，對方對價格有疑慮，我嘗試用案例說明 ROI，對方說會再考慮，我覺得自己在處理反對意見時還不夠有把握」

原則：說具體的數字、說你做了什麼、說結果是什麼、說你的感受或觀察。

### 3. 每週日：週報總結

每週固定進行一次週回顧：

```
/solo-coach-weekly
```

教練會：
- 整理這週的進展
- 找出哪些方法有效、哪些需要調整
- 更新你的目標進度
- 規劃下週的重點方向

週報通常需要 15 到 30 分鐘，建議選一個不趕時間的週日下午。

### 4. 建立習慣的實用技巧

設定手機提醒：
- 早上 8:30：「開啟晨間教練」
- 下午 5:30：「完成今日 check-in」

這兩個提醒能大幅降低忘記的機率，尤其是前三週最重要。

---

## 常見問題

問：忘記 check-in 好幾天了，還能繼續用嗎？

答：完全沒問題。教練會從你上次的狀態繼續，你只需要在下次 check-in 時簡單說明「這幾天的情況」，教練會自動重新校準，不需要重新設定或補回所有紀錄。

問：晨間教練和 check-in 一定要每天都做嗎？

答：不強制，但頻率越高，教練對你的了解越深，建議至少維持每週 3 到 4 次。如果某天真的很忙，至少做 check-in 就好，因為那是教練學習數據的主要來源。
